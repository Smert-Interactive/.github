# Общие настройки GitHub организации Smert Interactive

Этот репозиторий содержит общие правила и шаблоны для проекта DiceBound.

- [`CONTRIBUTING.md`](CONTRIBUTING.md) — порядок внесения изменений.
- [`GIT_WORKFLOW.md`](GIT_WORKFLOW.md) — ветки, коммиты, Pull Request и слияния.
- [`PULL_REQUEST_TEMPLATE.md`](PULL_REQUEST_TEMPLATE.md) — общий шаблон Pull Request.
- [`.github/ISSUE_TEMPLATE`](.github/ISSUE_TEMPLATE) — общие формы Issues.
- [`profile/README.md`](profile/README.md) — профиль организации.

Документация по запуску и особенности конкретного сервиса должны находиться в
соответствующем репозитории DiceBound.
